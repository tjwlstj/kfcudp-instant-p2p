# B02 · 직결 타임아웃과 세션 내 실패 기억

**상태: PLANNED.** [원래 조사](../feature-role-optimization.md)에서 분리한 독립 작업이다. [공통 검증 규칙](README.md)을 적용한다.

- **확인·추정:** [`WebRtcClient`](../../../src/client/java/kfc/udp/client/webrtc/WebRtcClient.java)의 1차 직결 시도는 2초다. 먼 시그널링 서버에서 불필요한 릴레이로 전환되는 빈도는 미측정이다.
- **선행·최소 변경:** `SignalingRtt`, 직결 성공률, TURN 전환 시간을 기록한 뒤 RTT에 따른 타임아웃만 먼저 시험한다. 같은 방장·네트워크의 직결 실패 기억은 그다음 단계다.
- **검증·되돌리기:** 경계값과 세션 범위 캐시를 정적·계약 시험하고 빌드한다. 실게임에서 빠른/먼 서버·직결 불가망의 접속 시간과 선택된 경로를 비교한다. 기본 2초 정책으로 원복 가능해야 한다.
