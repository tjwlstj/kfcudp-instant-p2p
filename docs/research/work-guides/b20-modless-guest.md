# B20 · 모드 없는 게스트 접속

**상태: PLANNED.** [원래 조사](../feature-role-optimization.md)에서 분리한 독립 작업이다. [공통 검증 규칙](README.md)을 적용한다.

- **제안:** 게스트의 일반 TCP 접속을 받아줄 서버 프록시가 필요하다. 현재 클라이언트 저장소만으로 완성할 수 없는 장기 기능이다.
- **선행·최소 변경:** 별도 서버의 비용·인증·남용 방지와 프로토콜 경계를 먼저 설계하고 제한된 로컬 프로토타입을 만든다.
- **검증·되돌리기:** 서버 용량·권한·트래픽과 Minecraft 접속을 별도 시험한다. 기존 P2P 경로를 유지한 채 실험 기능을 끈다.
