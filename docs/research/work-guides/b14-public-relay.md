# B14 · 공개 방의 릴레이 권장 또는 기본값

**상태: PLANNED.** [원래 조사](../feature-role-optimization.md)에서 분리한 독립 작업이다. [공통 검증 규칙](README.md)을 적용한다.

- **확인:** 공개 방 코드는 목록에 노출되며 직결은 두 피어의 네트워크 주소를 서로 드러내는 WebRTC 특성을 가진다.
- **선행·최소 변경:** UI 설명과 현재 기본 설정을 조사해 경고 문구부터 제공한다. 기본값 변경은 TURN 비용·연결 성공률·사용자 선택을 측정한 뒤 결정한다.
- **검증·되돌리기:** 설명과 실제 선택 값의 일치를 정적 검토·빌드·실게임에서 확인하고 직결/릴레이 선택을 각각 시험한다. 기본값 변경은 설정 한 곳으로 되돌린다.
