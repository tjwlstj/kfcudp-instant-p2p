# B12 · 프로토콜 버전·기능 협상

**상태: PLANNED.** [원래 조사](../feature-role-optimization.md)에서 분리한 독립 작업이다. [공통 검증 규칙](README.md)을 적용한다.

- **확인:** peer 이름 `j{r|d}{sid}`/`h{r|d}{sid}`에 모드 기능 정보가 없다. 공개 로비 ID에는 `MOD_VERSION` 해시가 들어간다.
- **선행·최소 변경:** 서버의 peer 이름 제약을 확인하고 페어 메시지에 새 모드가 무시 가능한 기능 필드 한 개를 추가한다. 원본 모드와의 fallback을 먼저 정의한다.
- **검증·되돌리기:** 알 수 없는 필드·원본↔포크·서로 다른 버전의 계약 시험과 빌드, 실게임 교차 접속을 확인한다. 협상 실패 시 기존 경로를 유지한다.
