# B16 · 연결 진단 화면

**상태: PLANNED.** [원래 조사](../feature-role-optimization.md)에서 분리한 독립 작업이다. [공통 검증 규칙](README.md)을 적용한다.

- **확인·제안:** 현재 경로에는 `bufferedAmount`, 직결/릴레이 여부와 [B01](b01-callback-isolation.md)의 대기 계측 지점이 있다. 사용자용 한 화면 표시는 아직 설계다.
- **선행·최소 변경:** 민감한 주소·토큰을 표시하지 않는 계측 DTO를 먼저 만들고, 화면에는 연결 상태·경로·최근 지연만 보여 준다.
- **검증·되돌리기:** 수치 소유권·리셋·개인정보를 정적 검토하고 빌드·실게임에서 직결/릴레이/실패 값을 확인한다. 화면을 끄면 전송 동작은 그대로여야 한다.
