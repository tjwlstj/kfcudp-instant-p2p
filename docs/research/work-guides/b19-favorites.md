# B19 · 즐겨찾기·최근 방

**상태: PLANNED.** [원래 조사](../feature-role-optimization.md)에서 분리한 독립 작업이다. [공통 검증 규칙](README.md)을 적용한다.

- **제안:** 클라이언트만 바꾸는 UI/저장 기능으로 아직 구현되지 않았다.
- **선행·최소 변경:** 저장할 최소값(코드·표시명·최근 접속 시각)과 비공개 코드 보관 위험을 결정한 뒤 즐겨찾기 추가/삭제부터 만든다.
- **검증·되돌리기:** 저장 파일 마이그레이션과 코드 노출을 정적 검토하고 빌드·게임 재시작 후 표시/삭제를 확인한다. 저장 파일을 읽지 않아도 방 접속 기능은 유지한다.
