# 08 · Minecraft 버전 어댑터부터 작은 추출

**상태: PLANNED.** 01~04가 안정된 뒤 착수한다. 트리 구조 개편은 기능 변경과 별도 커밋으로 다룬다.

- **소스 확인:** [`KfcudpClient`](../../../src/client/java/kfc/udp/client/KfcudpClient.java)와 화면 코드에 Stonecutter 버전 분기가 크고 중복된다. 연구 문서의 비활성 분기 행 수는 휴리스틱 계산이다. [`코드 트리`](../code-tree.md)는 Minecraft API 어댑터 분리를 계획으로 표시한다.
- **추정:** 분리만으로 빌드 시간·런타임 성능이 좋아진다는 증거는 없다. 주목적은 중복과 변경 범위 축소다.
- **제안·최소 변경:** 이미 있는 `kfcudp$tell` 또는 `kfcudp$playerCount` 한 함수를 `compat/`의 작은 인터페이스로 옮기고 기존 공개 진입점은 위임만 하게 한다. 방 생명주기, GUI, 네트워크 형식은 첫 단계에서 그대로 둔다.
- **정적 게이트:** 호출 그래프, 각 버전의 조건부 컴파일 분기, import, 코드 트리 소유 위치를 대조한다. bytecode/API 반사를 새로 도입하지 않는다.
- **빌드 게이트:** 적어도 1.21.x·26.x 대표 빌드. 이 작업은 Stonecutter 전반에 영향을 줄 수 있어 완료 주장 전 전체 17개 빌드를 실행한다.
- **실행 게이트:** 영향을 받은 UI·알림·방 생명주기 호출을 각 메이저 버전에서 확인한다. 빌드 성공만으로 Mixin 적용은 입증되지 않는다.
- **되돌리기:** 첫 추출 파일과 위임 호출만 되돌릴 수 있도록 작은 커밋으로 유지한다.
