# B17 · 두 번째 TCP 연결을 위한 다중 터널

**상태: PLANNED.** [원래 조사](../feature-role-optimization.md)에서 분리한 독립 작업이다. [공통 검증 규칙](README.md)을 적용한다.

- **확인·제안:** 현재 게스트는 단일 로컬 리스너 연결을 터널링한다. AutoModpack 등 두 번째 TCP 연결 지원은 [호환성·모드팩 조사](../compatibility-and-modpack.md)의 별도 설계다.
- **선행·최소 변경:** B12 기능 협상 후 연결 ID와 수명 메시지를 정의하고 두 번째 연결만 실험한다. 첫 Minecraft 연결을 보존한다.
- **검증·되돌리기:** 연결 ID 재사용·순서·종료 계약 시험과 양쪽 빌드, AutoModpack의 두 연결·재접속·취소 실게임 시험이 필요하다. 미지원 피어에는 단일 터널로 제한한다.
