# B21 · 네이티브 DLL 임시 파일 조사

**상태: PLANNED.** [원래 조사](../feature-role-optimization.md)에서 분리한 독립 작업이다. [공통 검증 규칙](README.md)을 적용한다.

- **확인·추정:** 조사한 webrtc-java 로더는 비 POSIX 파일 시스템에서 추출 파일에 `deleteOnExit`를 건다. Windows 종료 뒤 실제 잔재 축적은 미확인이다.
- **선행·최소 변경:** [04b](04b-host-native-load.md)의 첫/반복 실행 계측에서 임시 폴더 파일의 생성·종료 후 상태만 기록한다. 재현 전에는 삭제 코드를 넣지 않는다.
- **검증·되돌리기:** 라이브러리 소유 파일과 다른 임시 파일을 구별하고, 정상/비정상 종료 후 반복 실행을 관찰한다. 대응이 필요하면 라이브러리 변경 또는 안전한 정리 정책을 별도로 검토한다.
