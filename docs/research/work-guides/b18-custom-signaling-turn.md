# B18 · 사용자 지정 시그널링·TURN

**상태: PLANNED.** [원래 조사](../feature-role-optimization.md)에서 분리한 독립 작업이다. [공통 검증 규칙](README.md)을 적용한다.

- **제안:** 운영 서버 의존을 줄이는 설정이다. 현재 기본 서버와 역할 경계는 [호환성·모드팩 조사](../compatibility-and-modpack.md)를 따른다.
- **선행·최소 변경:** 주소와 인증 정보의 설정·보관 정책부터 정의하고 로컬 테스트 서버 하나에만 연결할 수 있게 한다. 프로토콜 호환성이 확인되기 전에는 교차 서버 검색을 약속하지 않는다.
- **검증·되돌리기:** URL·TLS·인증 정보 비노출을 정적 검토하고 빌드·자체 서버에서 초대/공개 목록/재접속을 시험한다. 기본 서버 설정으로 즉시 돌아갈 수 있어야 한다.
