# 검수 기록

이 폴더는 포크 전체를 정해진 커밋 기준으로 점검한 **검수 기록**을 모은다. [연구 문서](../research/code-tree.md)가 구조와 제안을 설명한다면, 여기는 "그 시점의 코드가 실제로 어떤 상태였는지"를 남긴다. 검수마다 날짜 폴더 하나를 쓰고, 같은 폴더 안에서 요약 → 발견 목록 → 검증 기록 → 파일별 범위 순으로 읽으면 된다.

## 읽는 법

- **심각도**
  - **높음**: 일반 사용 경로에서 크래시·데이터 손실·보안 경계 붕괴가 난다.
  - **중간**: 특정 입력이나 환경에서 기능이 틀어지거나 보안이 약해진다.
  - **낮음**: 드문 조건, 견고성, 유지보수 문제다.
  - **정보**: 설계 메모나 문서 정합성이다.
- **근거**
  - **확인(소스)**: 코드를 읽어 확정했다.
  - **확인(실행)**: 스크립트나 하네스를 실제로 돌려 재현했다.
  - **확인(빌드)**: Gradle 빌드와 생성 JAR로 확인했다.
  - **추정**: 실게임, 서버 소스, 패킷 관찰 없이 판단했다.
- 줄 번호 링크는 기준 커밋의 GitHub 고정 링크다. 이후 커밋에서 줄이 밀려도 검수 당시의 코드를 가리킨다.
- 발견 ID(`R01` 등)는 해당 날짜 검수 안에서만 유일하다. 후속 작업 PR에서는 `2026-09-27/R01`처럼 날짜와 함께 인용한다.
